A Streamlit app to explore, filter, clean, and visualize CSV datasets interactively.

Link to deployed app: https://csv-file-explorer.streamlit.app/

## Features

### 📄 Dataframe Explorer

* Upload CSV – Load any dataset for exploration.
* Grouped Filters – Create multiple filter groups with AND/OR logic.
* Flexible Filtering – Apply numeric ranges or categorical value filters.
* Global Logic Control – Combine filter groups using AND/OR conditions.
* Live Filtering – Instantly view filtered results.
* Interactive Display – Explore filtered data in a dynamic table.

---

### 📊 Dataset Summary

* Overview Metrics – View total rows, columns, and missing values.
* Column Insights – See datatypes, unique values, and missing counts.
* Numerical Statistics – Access min, max, mean, median, and standard deviation.
* Top Values – Quickly inspect most frequent values per column.

---

### 🧹 Data Cleaning

* Missing Data Overview – Identify missing values and percentages per column.
* Drop Missing Entries – Remove rows with missing values in one click.
* Manual Editing – Edit dataset directly using an interactive table.
* Save Changes – Apply edits back to the main dataset.

---

### 📈 Build a Plot

* Multiple Chart Types – Create scatter, line, bar, histogram, box, violin, pie, and heatmap charts.
* Column Selection – Dynamically choose relevant columns based on chart type.
* Flexible Data Source – Toggle between original, filtered, or both datasets.
* Color Grouping – Enhance plots by grouping data with categorical columns.
* Live Preview – Instantly visualize plots before saving.

---

### 📊 Visualization Dashboard

* Save Plots – Add custom visualizations to a persistent dashboard.
* Responsive Layout – Adjust number of plots per row.
* Edit Plots – Modify chart settings directly from the dashboard.
* Remove Plots – Easily delete unwanted visualizations.
* Side-by-Side Comparison – Compare original vs filtered data visually.
