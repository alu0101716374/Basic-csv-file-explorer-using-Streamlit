A Streamlit app to explore, filter, and clean CSV datasets interactively.

Features
- Upload CSV – Load any dataset for exploration.
- Grouped Filters – Create multiple filter groups with AND/OR logic for numeric ranges or categorical values.
- Dataset Summary – View dataset overview, numerical statistics, and top values per column.
- Missing Data Handling – Detect missing entries, drop rows, fill numeric columns, and manually edit cells.
- Interactive Display – See filtered data live and save manual edits.
